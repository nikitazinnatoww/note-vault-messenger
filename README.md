# Note Vault — Aesthetic Dark Messenger Prototype

Aesthetic, high-end cryptographic messenger UI prototype inspired by Apple Dark Mode, Linear, Teenage Engineering, and Tiempos Text typography.

## Features
- **Mobile Version (iOS / iPhone)**:
  - 4 interactive screens: Active encrypted messages list, interactive conversation with voice waveforms, authentic email onboarding, and language selector.
  - SideMenuView slide-out drawer with zero-knowledge keys and user dossier.
- **PC Version (Note Vault Console)**:
  - Avant-garde 4-column cryptographic workstation layout.
  - Live HUD ribbon with node latency, cipher telemetry, and key rotation countdown.
  - Enclave Matrix (Chats, Session Keys, Encrypted Notes).
  - Transmission timeline stream with signed cards, ephemeral self-destructing notes, and tactile audio spectrum deck.
  - Floating capsule composer dock.
  - Live Entropy Matrix inspector with real-time hexadecimal stream.
- **Switchable Platforms**: Instant toggle between Mobile and Desktop PC modes.
